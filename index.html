CASE 01 — CRYPTOGRAPHIC PROTOCOL RESEARCH

DSPD: Device-Bound Stateless Password Derivation Scheme

Argon2id HKDF-SHA256 Random Oracle Model Security Proofs PyPI Package
Research Problem
Standard password-derived keys are only as secure as the password string itself; a breach on one service exposes identical credentials elsewhere. Conventional key derivation functions (KDFs) do not cryptographically bind derived key material to the physical device generating it.
Theoretical Approach
Co-authored a device-bound stateless password derivation scheme with research supervisor Adil Khan. Formulated rigorous mathematical proofs under the Random Oracle Model across key indistinguishability and derivation soundness theorems.
What I Engineered
Identified and closed a critical domain-separation vulnerability in the HKDF input-keying-material construction prior to submission. Engineered and published a companion Python package and CLI with cross-hardware benchmark suites to PyPI.
Verified Status
Research manuscript submitted to an Elsevier journal venue, currently at Major Revision stage addressing formal security proofs and comparative baseline analysis (Under peer review — not yet formally published).
✓ Security proofs reviewed · Domain separation resolved · PyPI package published Status: Under Peer Review (Major Revision)
CASE 02 — MULTIMODAL AI & HEALTHCARE SYSTEMS (FYP)

AutismLens: Multimodal Manual-Grounded Autism Assessment AI

FastAPI LangChain Sentence-BERT ChromaDB OpenCV Next.js
Problem Formulation
Standardized autism screening instruments (e.g. Vineland-3) capture rich behavioral item data, but manually cross-referencing evaluation sheets against printed scoring manuals is slow, inconsistent across staff experience levels, and error-prone in under-resourced clinics lacking specialist staff.
5-Layer Architecture
Designed an incremental 5-layer pipeline: (1) Multimodal Intake (Form/PDF/Photo) → (2) CV & OCR Mark Extraction → (3) Digitized Manual Vector Store (Sentence-BERT + ChromaDB) → (4) Passage-Grounded LLM Interpretation → (5) Downloadable Structured Clinical PDF Report.
Zero-Hallucination Guardrails
To prevent diagnostic hallucinations, the LLM module is strictly prompted to ground every substantive statement in a retrieved passage cited from the digitized scoring manual, normalizing extracted item-level score vectors before synthesis.
Project Context & Status
Final Year Project (FYP-I) at Bahria University, Islamabad, supervised by Dr. Faryal Nosheen, in collaboration with Abdul Rehman. Evaluated on synthetic de-identified assessment sheets (Proposal stage & active incremental development).
✓ 5-Layer pipeline designed · Sentence-BERT + ChromaDB manual retrieval · Zero-hallucination citations Bahria University CS Dept · FYP-I

Data Engineering (~30,350 Docs)
