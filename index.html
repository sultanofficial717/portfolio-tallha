CASE 01 — CRYPTOGRAPHIC RESEARCH

DSPD: Device-Seeded Password Derivation

Cryptography Formal Proofs Security Proofs HKDF
Problem
Password-derived keys are only as strong as the password itself, and standard KDFs don't bind key material to the physical device generating it — leaving schemes vulnerable if a password is breached elsewhere.
Approach
Designed a device-seeded derivation scheme and formalised its security under the random oracle model, developing a rigorous proof structure across multiple theorems covering key indistinguishability and derivation soundness.
What I Built
A cryptographic construction plus a written security proof, developed through iterative peer review — including identifying and closing a domain-separation vulnerability in the HKDF input-keying-material construction prior to submission.
Verified Result
Journal revision addressing formal security proofs, comparative analysis, and technical depth flagged in earlier editor feedback — solidifying the scheme's mathematical credibility.
✓ Proof structure reviewed · Domain-separation issue resolved Target: Cryptographic Journal Revision
CASE 02 — SECURITY / ML RESEARCH

Ransomware Detection: A Survey of the Landscape

Machine Learning Security Research IEEE Access Benchmarking
Problem
Ransomware detection literature is fragmented across static, dynamic, and hybrid ML approaches, lacking a clean systematic map of what works, what has been tested, and where the remaining research gaps are.
Approach
Co-authored a structured survey manuscript for a Q1 target venue (IEEE Access), categorising detection approaches and benchmarking studies, then put it through an exhaustive senior-editor-style peer review.
What I Built
Two full manuscript revisions, each independently scored — feedback surfaced issues from a missing competing survey to internal benchmark-count inconsistencies and reference attribution errors, all rigorously resolved in revision.
Verified Result
A hardened manuscript with corrected benchmark figures, closed citation gaps, and comprehensive prior-art coverage — currently in the Major Revision stage ahead of final resubmission.
✓ Two review cycles complete · Revision in progress Target: IEEE Access (Q1 Venue)
CASE 03 — APPLIED AI SYSTEMS

Self-Hosted Whitelabel AI Marketing Platform

LangGraph FastAPI RAG pgvector Ollama
Problem
Running cold outreach and client acquisition at HAT Technologies meant repeating manual research, drafting, and personalization for every campaign — an operational bottleneck that did not scale with headcount.
Approach
Designed a fully local, self-hosted architecture built around specialized AI agent "employees", using OpenHermes via Ollama for local reasoning so client and lead data never leaves the local environment.
What I Built
A multi-service build spec covering FastAPI, LangGraph, PostgreSQL with pgvector, Redis, Celery, and Next.js — plus live outreach campaigns across Pakistani F&B and international health/wellness prospects with distinct messaging frameworks.
Verified Result
A reusable architecture for agentic marketing workflows, and active outreach campaigns using pain-point-led personalization, channel-specific CTAs (WhatsApp for local, Calendly for international), yielding measurable response gains.
