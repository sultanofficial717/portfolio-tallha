# Talha Rehman — AI & ML Engineer Portfolio

Personal portfolio and interactive AI agent for **Talha Rehman** (AI & ML Engineer, Business Development Manager at HAT Technologies, and Academic Researcher at Bahria University).

This repository merges classic clean portfolio architecture with an interactive, verified AI portfolio agent and live verification terminal.

---

## 🚀 Key Features

- **Interactive Personal AI Agent (`talha-portfolio-agent`)**: A retrieval-only client-side agent with zero fabrication guardrails, suggested query chips, citations, and instant search.
- **Terminal Verification Log (`verification_log.sh`)**: Live animated bash verification engine demonstrating proof statements and review passes.
- **Dark & Light Mode Support**: Signature dark ink theme and warm paper light theme with persistent user preference.
- **Deep-Dive Case Studies**:
  1. *DSPD: Device-Seeded Password Derivation* (Cryptographic Research / Formal Proofs / HKDF)
  2. *Ransomware Detection: A Survey of the Landscape* (Security / ML Research / IEEE Access Target)
  3. *Self-Hosted Whitelabel AI Marketing Agency Platform* (LangGraph, FastAPI, pgvector, Ollama)
- **Categorized Technical Matrix**: Agentic AI, Backend & Data, Frontend, Cryptography, Research, and Go-to-Market.
- **Experience Timeline**: Structured career history covering HAT Technologies, Bahria University, and independent AI engineering.
- **Projects Grid**: Expandable prototypes, reference implementations, and research benchmark suites.
- **Responsive & Accessible**: Seamless fluid layouts for desktop, tablet, and mobile with active scrollspy and floating back-to-top button.

---

## 🛠️ Stack

- **Frontend**: HTML5, Modern CSS (CSS Variables, Flexbox/Grid, Glassmorphism), Vanilla JavaScript (Zero bloated runtime dependencies)
- **Typography**: Fraunces (Editorial Serif), Inter (Body UI), JetBrains Mono (Terminal & Code)
- **AI / Data**: Client-side RAG & Retrieval Engine, Vector & Keyword Matching
