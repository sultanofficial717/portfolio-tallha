# Portfolio Update Checklist

Use this checklist whenever adding a new case study, project, or milestone to the portfolio:

- [ ] Define the real problem being solved
- [ ] Document what I did (role, approach, tech stack, key architectural decisions)
- [ ] Document genuine outcomes only (no fabricated metrics or publication claims)
- [ ] Add case study to the existing Research / Case Studies section (`<section id="work">` or `<section id="projects">`)
- [ ] Add supporting image/media if available (optimized `.webp` or `.png` in `img/`)
- [ ] Add GitHub / demo / paper links if available and verified
- [ ] Verify the AI Voice Agent still works (click Hero call button, test voice connection)
- [ ] Update the Voice Agent `knowledgeBase` in `index.html` with new keywords/phrases if applicable
- [ ] Test desktop layout (1440px / 1080px)
- [ ] Test mobile layout (responsive drawer, card stacking at 375px–768px)
- [ ] Run production checks / validate HTML and JavaScript syntax with zero errors
- [ ] Stage, commit, and push to GitHub `main`
- [ ] Open the live portfolio on Vercel (`https://portfolio-tallha-7ql2.vercel.app/`)
- [ ] Verify the new case study renders cleanly on the live site
